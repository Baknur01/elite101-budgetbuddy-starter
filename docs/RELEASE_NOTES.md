# Release Notes

Every time your squad ships something, add a short entry at the top. Newest
release goes first. Keep each entry to what a user would notice.

## Format

```
## v1.0 - YYYY-MM-DD
### Added
- Short, user-facing description of a new feature (link the ticket #).
### Fixed
- What was broken and now works.
### Changed
- Anything that behaves differently than before.
```

## v1.0 - 2026-11-10

### Added
- First release of BudgetBuddy: check your balance, list and add transactions, filter by category, and see your last transaction (#23).
- Quick summaries: how many transactions are in each category, how much you've spent, and an account overview (#23).
- Transactions you add are saved, so they're still there the next time you open the app.

### Fixed
- No fixes in this release. Bug fixes from our bug bash (#16, #17, #18, #19) are still in review and will ship in the next release.

### Changed
- The README now lists every menu option, how to run the app and tests, and the known limitations.
